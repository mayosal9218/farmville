# FarmLedger

A simple local farm-record web app. It stores daily activities, expenses, sales, crops, and livestock in SQLite—without writing SQL.

## Start it on Windows

1. Open this project folder.
2. Run `py setup_database.py` once to create the database.
3. Double-click `run_app.bat`.
4. Open [http://localhost:8000](http://localhost:8000).

Use the navigation menu to add farm records. Press Ctrl+C in the Command Prompt window to stop the app.
